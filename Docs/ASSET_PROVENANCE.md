`5fb07f77dc82c2c3c71d2185653a5735e5cfc4f0`

The same complete tree SHA appears in:

- `Dusk-92/FishingBuddy`
- `refaim/FishingBuddy`

unchanged from the immediate upstream baseline.

The older `aim2kill/FishingBuddy` icon tree has a different tree SHA
(`d6fd2e2f41378945cb2cb7280c7d310f409fea88`), so the current icon set should
be attributed immediately to the later upstream history rather than assumed to
be byte-identical to that older snapshot.

## Provenance boundary

An exact Git match establishes immediate file provenance. It does not establish
the ultimate creator of every visual, nor does it grant additional rights in
game-derived or third-party artwork.

The current official Fishing Buddy projects maintained by Sutorix are marked
"All Rights Reserved", and no separate asset license was identified during this
audit.

Therefore:

- no claim is made that Dusk-92 created these icons;
- no claim is made that `refaim/FishingBuddy` originated every underlying
  visual element;
- no permissive asset license is asserted by this fork;
- the files are retained with their immediate provenance documented.

## Game/trademark boundary

World of Warcraft, Warcraft, Blizzard Entertainment, and associated names,
marks, artwork, interface elements, and game assets remain the property of
their respective rights holders.

## Maintenance

When an icon or other visual asset is added, removed, or replaced:

1. record its source or creation history;
2. preserve upstream attribution;
3. record exact hashes where practical;
4. do not infer a license from repository visibility alone;
5. retain historical provenance if an asset is replaced.
